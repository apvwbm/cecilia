## What it does

- **Your own list**, like a notebook with tabs: nouns, verbs, adjectives, idioms and adverbs.
  Each word with its translation and your own way of saying it: *hello*, *hola*, /jelou/.
- **Two cards for every word**: see it in English and think of what it means, or see it in
  Spanish and type it in English. Recognising a word and using it are not the same thing, so
  each card keeps its own pace.
- **You mark yourself** with three faces: got it, more or less, or no idea. Nothing is
  corrected for you: you know when you knew it.
- **Spaced repetition, like Anki**: the words you miss come back sooner, the ones you know come
  back less and less often (tomorrow, in 3 days, in a week, in 3 weeks…). A missed card comes
  back a few cards later in the same round, until you get it.
- **As much as you want**: choose how many words each round (10, 20, 30, 50 or any number) and
  go again when you finish. Each round brings the words you need most.
- **A timer** that counts up while you revise. No countdown, no pressure.

For Spanish speakers learning English: the app is in English and your translations are in
Spanish.

## Privacy

Everything is stored encrypted on your phone and the app has no internet permission. No
accounts, no ads, no tracking.

Your words live only on your phone, so make a backup from time to time (the icon in the corner
of the home screen). Backups are encrypted with a password only you know.

## Install

Download `cecilia.apk` from
[the latest release](https://github.com/apvwbm/cecilia/releases/latest) and open it on your
phone. To update, install the new one on top: your words are kept. Don't uninstall it first,
that deletes them.

<details>
<summary>For developers</summary>
<br />

Expo SDK 58 · React Native · TypeScript · SQLite encrypted with SQLCipher.

```bash
npm install && npm start   # Expo Go (no encryption, no backups)
npm run verifica           # logic tests
npm run apk                # APK on the Desktop (Linux or Windows + Android SDK)
python3 scripts/iconos.py  # regenerate the icon
```
